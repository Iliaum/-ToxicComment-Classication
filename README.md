# ToxicComment-Classification

Решение задачи многоклассовой классификации текста на основе соревнования Kaggle: Jigsaw Toxic Comment Classification Challenge.

## Цель проекта

Разработать NLP-модель, способную определять различные типы токсичности в комментариях пользователей.  
Каждый текст оценивается как мультилейбл-задача по 6 категориям (комментарий может принадлежать сразу к нескольким):

- `toxic` (токсичный)
- `severe_toxic` (особо токсичный)
- `obscene` (нецензурный)
- `threat` (угроза)
- `insult` (оскорбление)
- `identity_hate` (ненависть по признакам идентичности)

## Результаты

Метрика соревнования — **mean column-wise ROC AUC**.

| Модель | Признаки | Mean ROC AUC |
|---|---|---|
| MultinomialNB | CountVectorizer (counts) | 0.924 |
| LogisticRegression | TF-IDF (1,2)-граммы | 0.972 |
| LinearSVC | TF-IDF (1,2)-граммы | 0.967 |
| **BiLSTM + attention** | обучаемые эмбеддинги (dim=128) | **0.981** |

**ROC AUC по классам (LogReg + TF-IDF):**

| Класс | ROC AUC | F1@0.5 | F1@best | Порог |
|---|---|---|---|---|
| `toxic` | 0.972 | 0.716 | 0.772 | 0.25 |
| `severe_toxic` | 0.986 | 0.311 | 0.499 | 0.10 |
| `obscene` | 0.984 | 0.741 | 0.798 | 0.15 |
| `threat` | 0.985 | 0.336 | 0.503 | 0.15 |
| `insult` | 0.979 | 0.647 | 0.741 | 0.20 |
| `identity_hate` | 0.973 | 0.184 | 0.426 | 0.10 |
| **mean / micro** | **0.972** | — | **Micro F1 = 0.737** | — |

**Ключевые выводы:**

- Классы сильно несбалансированы (89.9% комментариев без меток), поэтому accuracy неинформативна — использованы ROC AUC, PR-кривые и F1.
- Для всех классов оптимальный порог < 0.5 (0.10–0.25). Прирост F1 максимален для редких классов: `identity_hate` +0.24, `severe_toxic` +0.19, `threat` +0.17.
- BiLSTM + attention даёт +0.009 AUC над TF-IDF+LogReg, обучается за 5 эпох без переобучения.
- OOV rate на валидации 3.05% — словарь из 30 973 токенов покрывает 97% текста.
